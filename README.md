# Carte sociale du vote

Les inscrits sur les listes électorales répartis par âge et par diplôme, et la répartition de leurs intentions de vote au premier tour de l'élection présidentielle de 2027 selon les sondages publiés. Chaque électorat occupe une surface proportionnelle à ses voix.

Le site est statique : il suffit de servir ce dossier (par exemple `python3 -m http.server`) et d'ouvrir `index.html` (présentation), puis `carte.html`.

La méthode, les sources et les limites des estimations sont décrites dans les pages « Méthodes » et « Limites » du site. Ce dépôt ne contient que le site et ses données agrégées ; le code de calcul n'y figure pas.
